# AI System

AI is used for resume analysis, job analysis, question generation, answer feedback, resume rewriting, cover letters, and optional roadmap explanations. Python handles validation, exact/semantic matching, averages, thresholds, ATS estimates, trends, priority, mastery, readiness, and study duration.

Every AI response is parsed and validated before it reaches the UI or database. Prompts provide structured source context and prohibit fabricated candidate facts. AI-generated scores are not trusted for deterministic application metrics.
